# reports/ — generated artifacts (bot-owned)

Every file here is **regenerated by `panthera-mvp report`** (or `grade` /
`picks`, which call it) from `data/picks/picks.csv`. Never edit the markdown
directly — change `src/panthera_mvp/report.py` and regenerate.

- `BETTING_REPORT.md` — the running ledger and the strategy verdict. Contains
  pre-registered success criteria (≥100 graded picks; ROI > 0% supported,
  < −5% falsified) — do not move those goalposts after the fact.
- `daily/YYYY-MM-DD.md` — per-day picks, grades, movement, passes, credits.
- `CALIBRATION.md` — written by `panthera-mvp calibrate`; documents how the
  P/V day map and thresholds were derived and its caveats.
